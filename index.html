Windows · 桌面灵动岛

浮屿 岛上套件

基于浮屿 Fuyu（Tauri 2 / AGPL-3.0）改造的桌面信息层：胶囊 / 面板 / 中心三层，材质随桌面壁纸实时自适应，CPU·内存·GPU·网速·电量·磁盘·温度一张设备卡收完。

三层结构

  • 第一层·胶囊：常驻顶栏，时间 + CPU / 内存微条 + 通知点，材质极低存在感。
  • 第二层·面板：点胶囊展开，时间头、五枚页签、议程与快捷入口，日常操作全在这里。
  • 第三层·中心：再点一次弹出完整中心，设备卡（CPU / 内存 / GPU / 上下行 / 电量 / 磁盘 / 进程 / 温度）、待办、通知、Obsidian 笔记一屏收完。
  • 待办、通知、快捷都从面板下沉为独立小卡，面板上不再堆文字。

背景自适应

  • 取背后区域的平均亮度与主色，亮壁纸自动转深色吸光玻璃，暗壁纸用提亮反光玻璃，彩色壁纸给一层同色相薄染。
  • 背景光会从玻璃里透出来（blur 28px + saturate 165%），不是把岛贴在不透明的黑块上。
  • 面板宽度用 min(560px, 100vw - 48px)，窄屏下双列卡片自动堆叠为单列；高度按内容多少自动伸缩。

安装说明

  • 下载后放到固定目录，直接双击 fuyu.exe 运行；配置在 %USERPROFILE%/.fuyu。
  • 数据全部保存在本机，不上传云端；MCP 接口只对本机开放。
  • 本项目为浮屿衍生版，遵循 AGPL-3.0，源码改动同样开源。
