Windows · 桌面信息层

屿

胶囊 / 面板 / 中心三层，材质随桌面壁纸自适应；内核模块化，加能力只需登记一条模块。底层基于 Fuyu（Tauri 2 / AGPL-3.0），界面与信息架构已重做。

下载安装包 GitHub Releases
版本0.3.11-beta.1
体积43.8 MB
系统Windows 10 / 11 x64

三层结构

  • 胶囊：双任务实况窗（日程 + 媒体），44px 全圆角，低存在感。
  • 面板：时间头、文字胶囊页签、议程；点时间头形变展开成中心。
  • 中心：设备、待办、通知、笔记，一屏收完；待办与通知可互相转换。

内核模块

  • src/kernel/：模块注册表（registry）、事件总线（bus）、背景自适应（ambient）。
  • 新增能力：写组件 → modules.ts 登记 order 与 layers → 壳层按层装配，不改导航与样式。
  • 背景采样走原生 backdrop_sample，缺值时按系统外观与时段兜底，结果只写在 CSS 变量上。

背景自适应

  • 亮壁纸转深色吸光玻璃，暗壁纸提亮反光，彩色壁纸薄染同色相。
  • 玻璃透背景（blur 28px + saturate 165%），不是不透明黑块。
  • 面板宽 min(560px, 100vw - 48px)，窄屏四列变两列。

安装说明

  • 下载后放到固定目录直接运行；配置在 %USERPROFILE%/.fuyu（沿用旧目录以保留既有数据）。
  • 数据全部本机，不上云；MCP 接口只对本机开放。
  • 本项目遵循 AGPL-3.0，修改后分发同样需要开源。
