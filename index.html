Windows · 桌面信息层

屿

胶囊 / 面板 / 中心三层，材质随桌面壁纸自适应；内核模块化，加能力只需登记一条模块。底层基于 Fuyu（Tauri 2 / AGPL-3.0），界面与信息架构已重做。

系统Windows 10 / 11 x64

三层结构

  • 胶囊：双任务实况窗（日程 + 媒体），全圆角、低存在感；主文本 1–3 字、副文本 1–6 字。
  • 面板：时间头、滑动式页签、议程焦点卡；卡片按 60ms 错峰浮起。
  • 中心：命令栏 + 数据中心 + 待办 / 通知 / 笔记；待办与通知可互相转换。

数据中心

  • 单例采样：面板与中心共用一个轮询，不再重复拉取 system_stats。
  • 趋势带：CPU / 内存 / 下行各 32 点迷你折线，按自身区间自动缩放，小幅波动也看得见。
  • 超 80% 转橙告警；GPU、上行、磁盘、温度待原生字段接入。

极简工作台

  • 顶部命令栏：/ 或 ⌘K 聚焦，Esc 清空，过滤待办 / 通知 / 笔记 / 剪贴。
  • 每张卡一个主操作，不做僵尸按钮；点击笔记直接跳 Obsidian。

材质与动效

  • 指针跟随高光：hover 时卡片出现随光标移动的 specular 亮斑。
  • 焦点卡用同色薄底，比同级卡亮一档，不再一片同灰。
  • 动效令牌 --motion-fast/base/slow + --ease-spring；页签是滑动指示器而不是硬切。
  • 中心弹簧入场、行级按压反馈，全程尊重 prefers-reduced-motion。

内核模块

  • src/kernel/：模块注册表（registry）、事件总线（bus）、背景自适应（ambient）。
  • 新增能力：写组件 → 登记 order 与 layers → 壳层按层装配，不改导航与样式。
  • 背景采样走原生 backdrop_sample，缺值时按系统外观与时段兜底。

安装说明

  • 下载后放到固定目录直接运行；配置在 %USERPROFILE%/.fuyu（沿用旧目录以保留既有数据）。
  • 数据全部本机，不上云；MCP 接口只对本机开放。
  • 本项目遵循 AGPL-3.0，修改后分发同样需要开源。
